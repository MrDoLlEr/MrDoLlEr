# روتانا — هوية إدارة الموارد البشرية

ملف مرجع للعروض الداخلية. Widescreen ١٦:٩.

## ماذا في الملف

`dist/Rotana_HR_Identity_Kit.pptx`

٢٤ شريحة تُنسخ كما هي:

| شرائح | المحتوى |
| --- | --- |
| ٠١، ٢٤ | غلاف وشكر |
| ٠٣–٠٦ | ألوان بأكوادها، خطوط، شعار |
| ٠٧ | ماسكات صورة — Change Picture |
| ٠٨ | مكتبة أيقونات |
| ٠٩–١٠ | أرقام وشارتات قابلة للتعديل |
| ١١–١٢ | إدارات روتانا + وحدات HR |
| ١٣–٢٣ | تخطيطات عمل: فاصل، أجندة، نص، عمودان، ركائز، مسار، زمن، فريق، اقتباس، جدول، صورة |

## الألوان

من شعار روتانا + الرمادي الفاتح المطلوب:

- Forest `#00512F` — الأساسي
- Grove `#006C3C` — رسوم
- Leaf `#2BA86C` — لمسة
- Mist `#E8E8E4` — رمادي فاتح
- Ink `#0C100E` — أغلفة
- Stone `#C5C7C2` — خطوط

## الخطوط

ثبّت على الجهاز (موجودة في بيئة التصميم):

- Amiri للعناوين
- IBM Plex Sans Arabic للنص
- IBM Plex Sans للاتيني
- IBM Plex Mono للأكواد

## كيف تستخدمه

1. افتح الـ PPTX وانسخ الشريحة إلى عرضك.
2. للصور: حدد الصورة → Picture Format → Change Picture. الشكل يبقى.
3. للأرقام في شريحة ١٠: اضغط الشارت وعدّل البيانات.
4. لا تُعدّل ملف الأصل — اعمل نسخة.

معاينة بصرية: افتح `preview/index.html` عبر خادم محلي.
