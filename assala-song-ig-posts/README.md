# أصالة — بوستين تفاعليين لإنستغرام (تجربة)

مقاس النشر: **1080 × 1350** (4:5). عربي، من اليمين لليسار.

سلسلة من بوستين لنفس الإصدار، بآليتين تفاعل مختلفتين. الجمهور يرد في التعليق — هذي أقوى أداة تفاعل في فيد إنستغرام.

| ملف | الآلية | المزاج |
| --- | --- | --- |
| `exports/01-ayy-bayt-aqwa.png` | تصويت ١ أو ٢ على البيت الأقوى | ليلي |
| `exports/02-kammil-albayt.png` | كمّل البيت + منشن شخص وفيّ | نهاري |

إعادة الرسم:

```bash
python3 scripts/render_posts.py
```

المعاينة: `python3 -m http.server 8080` من هذا المجلد، ثم افتح `/preview/`.
