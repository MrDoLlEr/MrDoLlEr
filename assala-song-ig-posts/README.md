# أصالة — بوستين تفاعليين لإنستغرام (تجربة)

مقاس النشر: **1080 × 1350** (4:5). عربي، من اليمين لليسار.

الصور من مواد روتانا الرسمية لأصالة نصري — مش تايبوغرافي فاضي.

| الملف | الآلية | الصورة |
| --- | --- | --- |
| `exports/01-ayy-bayt-aqwa.png` | تصويت ١ أو ٢ على البيت الأقوى | بورتريه روتانا الرسمي |
| `exports/02-kammil-albayt.png` | كمّل البيت + منشن شخص وفيّ | غلاف «لحقت نفسي» |

إعادة الرسم:

```bash
python3 scripts/render_posts.py
```

المعاينة: `python3 -m http.server 8080` من هذا المجلد، ثم افتح `/preview/`.

مصادر الصور في `assets/source/SOURCES.md`.
